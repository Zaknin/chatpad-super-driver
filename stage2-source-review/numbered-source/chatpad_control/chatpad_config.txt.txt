     7	# File Format
     8	# ===========
     9	# Each line of the file can be empty, have a comment (starts with #),
    10	# or have a configuration line.  Configuration lines can be in any order,
    11	# but there should not be multiple lines for the same mapping or setting.
    12	# If there are multiple such lines, then the final one will take effect.
    13	#
    14	# In other words, if you map a key to F3, and then later in the file map the
    15	# same key to F9, then the key will end up acting like F9.
